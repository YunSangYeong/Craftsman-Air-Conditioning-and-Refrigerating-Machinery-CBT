## 실행

Node.js 24.19.0 / npm 11.9.0. 외부 서비스·로그인·비밀키 없이 작동합니다.

```sh
cd /workspace/Craftsman-Air-Conditioning-and-Refrigerating-Machinery-CBT
npm ci
npm run dev
npm test
npm run test:e2e
npm run build
```

브라우저 검사 전 `npx playwright install --with-deps chromium`으로 Chromium을 설치합니다. 이번 환경에서는 이미 설치된 `/usr/bin/chromium`을 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH=/usr/bin/chromium`으로 지정했습니다. 개발 서버·preview는 이후 세션에서 다시 시작해야 합니다. 기존 체크아웃을 사용하며 별도 worktree는 만들지 않습니다.

## 시험 규칙: 공식 원문 확인 미완료

설정은 [src/qualification.json](src/qualification.json)에 있습니다. 현재 학습용 설정은 다음과 같습니다.

| 과목 | 문항 | 내부 문제은행 |
| --- | ---: | ---: |
| 에너지관리 | 20 | 250 |
| 공조냉동설계 | 20 | 250 |
| 시운전 및 안전관리 | 20 | 250 |
| 유지보수 공조냉동 | 20 | 250 |

총 80문항 / 120분 / 4지선다. 과목별 100점 환산, 전체 평균 60점 이상이면서 **모든 과목 40점 이상**이어야 합격으로 계산합니다. 미응답은 오답이며 표시 반올림 전 비율로 판정합니다. 과목 내 문항은 동일 배점(5점), 전체 평균에서 문항당 1.25점입니다.

**위 항목은 이 실행에서 공식 확인된 시험 규칙이 아닙니다.** AI 일반 지식에서 구성한 학습용 설정입니다. Q-Net 공식 후보 페이지 `https://www.q-net.or.kr/crf005.do?id=crf00503&jmCd=1730`에 접근했으나 프록시가 `403 Forbidden`, `curl: (56) CONNECT tunnel failed, response 403`을 반환하여 본문·최신 출제기준 적용기간·공식 과목 표기·선정 방식·시험시간·합격 기준을 원문 대조하지 못했습니다. 취득 자격/실기 시험은 이 앱의 범위 밖입니다. 공식 규칙 재현 완료 또는 최신 출제기준 전 범위 대조 완료로 취급하지 마세요.

## 자체 제작 문제은행

실제 JSON 등록 및 내부 검수 상태 `reviewed`: **1,000개**, 수량상 부족 **0개**. 각 과목 250개입니다.

- 원문 기출 **0**, 복원 **0**, 자체 제작 **1,000**. 확인되지 않은 기출 연도·회차는 모두 `null`입니다.
- 전부 계산형 숫자 조건 변형입니다. **40개 공식/템플릿 family × 25조건**이며, 각 family의 첫 조건 40개와 추가 조건 변형 960개입니다. 1,000개의 독립 개념이나 1,000개 기출이 아닙니다. 비계산 개념 문항은 0개입니다.
- AI의 일반 공학 지식을 근거로 작성했습니다. 읽지 않은 외부 교재나 공식 자료를 인용하지 않습니다. 문항의 저장소 URL은 작성·검토 위치이며 외부 정답 증빙이 아닙니다.
- 원문 기출의 원문·공식정답·재배포 권한은 확보하지 못했습니다. 타사 문제를 수집하거나 재배포하지 않았습니다. 앱 코드는 원본 MIT 고지를 보존하며 새 자체 데이터는 CC BY 4.0입니다.
- 내부 검수는 40개 템플릿의 조건·공식·단위·해설 형식 검토와 1,000개 인스턴스의 독립 역산·반올림·단일 정답·중복 검사입니다. **외부 전문가 검수와 공식 출제범위 대조는 미완료**입니다. 내부 검수 상태를 그 검수로 해석하지 마세요.
- 정규화 문제/보기·ID 중복 0개. 의미상으로 같은 family의 25개는 의도적인 동형 연습입니다. family 간에도 현열/잠열, COP 등 관련 개념이 있어 40개를 독립 개념 수라고 주장하지 않습니다. 과목 분류는 학습용이며 실제 시험 난이도·전 범위 대표성이 부족합니다.
- 과목당 family가 10개이므로 한 시험에 family가 2번씩 등장합니다. 첫 순회에서 각각 한 번 선택한 뒤 두 번째 조건으로 보충합니다. 한 시험 내 ID 중복은 없습니다.

세부 근거·40개 템플릿 목록·재생성 방법은 [문항 검토 기록](docs/question-review.md)을 확인하세요. 법령 수치나 안전 허용기준을 임의로 만들지 않았으며 일부 안전관리 문항은 측정 계산일 뿐 법정 적합성 판정이 아닙니다. 이 문제은행만으로 시험 전 범위를 준비할 수 있다고 보장하지 않습니다.
